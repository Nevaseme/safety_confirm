# Webデモ 1.6.17：設定からの言語切り替え

2026-10-30

## 実装内容

- 1.6.16を残し、右側に1.6.17を追加。入口はメニュー → 設定 → 言語 / Language。
- 日本語・Englishを即時に切り替え、選択を同じブラウザーに保存する。初回は日本語。
- 地図の操作・読み上げ名、人物一覧と詳細、安否、対応・通報・資材、地域集計、表示条件とCSVの列名・定型値を翻訳。
- 未対応＝Not started、対応予定＝Acknowledged。担当割当・対応進捗の定義は従来どおり。
- UIの表示のみを変換する。内部の状態値・ID、公開範囲、3分の起点、入力値、人数と件数は変更しない。氏名・住所・寝室・昼間の場所・自由記述・資材名と単位は原文を維持する。地図配信元の地名も自動翻訳しない。
- 既存の比較画面は日本語のまま。Androidは今回の変更対象外。

## 設計・表示確認

既存の白・紺・青、Noto Sans JP、下部タブ、詳細シートを踏襲。言語選択は母語表記のラジオボタン2行。英語の長いラベルは折り返し、表は既存の横スクロール内に収める。装飾や新しい導線は追加しない。

Product Designとfrontend-designを適用。アプリ内ブラウザーで1.6.16と1.6.17の日本語地図を860×1000の同一画像で比較し、配置・配色・素材の維持を確認。390×844でも言語設定と対応状況のフォームに横方向のはみ出しがないことを確認した。
