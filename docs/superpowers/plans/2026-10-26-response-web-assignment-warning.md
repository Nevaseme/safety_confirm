# 対応Web案1.6.3：担当外の注意

## 利用者と確認した仕様

- 他の担当者が付いていて自分が担当していない通報には「あなたはこの通報の担当ではありません」と表示する。
- 利用者は「注意を表示し、変更はできる」を選択。注意表示で操作を禁止せず、既存の役割別の操作範囲を維持する。
- 自分の担当・自分を含む共同担当・担当者無しでは表示しない。
- 通報の詳細と変更画面（担当、対応状況・結果、緊急度、地域、通報訂正・取り消し、資材、取り消しの復元）に表示する。開始・復元等の直接操作は詳細で注意を先に確認できる。
- 注意は一時的なポップアップにせず、見出し内に残して操作ボタンを覆わない。自分が担当に加わると消え、外れて他の担当者が残る場合は再表示する。
- 旧比較画面を維持し、右側にWeb案1.6.3を追加。Android・plan.txtは変更しない。架空データ・再読込で初期化するデモ。

「地域を変更」は通報の地域別集計先の訂正。通報座標や担当者・班は変えない。今回は説明のみで、地域機能自体は変更しない。

## 検証

- [x] 自動試験18件と変更したモジュールの構文確認に成功。
- [x] Webで表示条件、注意を表示したまま保存可能、担当加入／解除と表示切替、スマートフォンの非重複、旧版維持を確認。
- [ ] 公開先への反映と操作を確認。

## ローカル確認

- 他の担当者のみの詳細・状況変更・担当変更・地域変更・緊急度・通報訂正・資材要請・取り消し・復元に注意を表示。
- 担当者無しの詳細・状況変更では注意0件。自分が共同担当へ加入すると注意0件、解除して北班だけになると注意1件。
- 注意を表示したまま状況変更を保存でき、担当を変更せず対応中へ更新できる。取り消しと復元も可能。
