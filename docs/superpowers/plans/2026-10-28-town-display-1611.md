# ver 1.6.11：自町内会の統計吹き出しを外し、建物の建築年を復元

利用者の指定：自町内会の統計吹き出しは不要。建物詳細には建築年を表示する。

旧比較画面を保持し、1.6.10の右に1.6.11を追加する。自町内会の非表示は一般住民・エリア管理者に適用し、3分前後で変えない。自治体職員は所属町内会に限定しない表示を維持する。

今回維持すると確認されたもの：町内会拡大、全町内会の安否統計表、安否統計CSV、デモ設定・経過時計・追加速報、取り消した通報の確認と復元、住所非表示時の寝室・建物属性・建物リンクの非表示、対応一覧の初期「すべて」。

人物一覧の省略については説明を求められたため、位置更新の経過時間・位置不明の寝室を勝手に戻さない。人数・氏名・住所・地点・観測・公開範囲・反応なしの3分待機・クラスタは変更しない。Android・plan.txtは変更しない。

過去の1.6.4以降の記録には、自町内会の待機中の統計を維持すると書かれているが、利用者の明示指示ではなく実装者の判断だった。本版では今回の明示指示を優先する。

## 確認

- 修正前の公開1.6.10で、開始直後に東町内会の統計吹き出しがあること、建物詳細に建築年がないことを再現した。
- 既存34試験と変更モジュールの構文確認が成功。
- ローカルの一般住民で東・中央・西へ切り替え、開始直後に自町内会の吹き出し0、他町内会2を確認。エリア管理者・西・4分後でも自町内会0、他町内会2。自治体職員は各町内会の3記号を維持。
- 3分後に位置不明の山田花子を開き、住居・寝室から「建物を見る」で建築年1986年・木造・2階建を確認。位置が分かる山田太郎には住所・寝室・建物リンクを表示せず、位置の時刻・精度・観測を維持。
- 旧1.6.10では開始直後の自町内会記号が残り、比較画面の動作を維持。人物一覧の表示は変更せず、対応一覧には「すべて」の5件を表示。ブラウザーのエラー0件。
- 公開先への反映と公開版の確認は実施後に記録する。
