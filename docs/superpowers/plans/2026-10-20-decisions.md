## 今回確認した決定

| 項目 | 利用者の回答 |
|---|---|
| Web比較画面（2026-10-22） | 従来画面を左に残し、右に地図／一覧／安否の新構成を追加。全員とSOSは共通一覧の絞り込みで切り替える。位置不明の入口を残し、吹き出しからその中の人を一覧表示する。Androidへの追加移植は未着手 |
| エリア一覧の見出し | 「このエリアの○人」。グループ全体の一覧とは対象範囲を区別する |

| 衝撃素材（Web比較版） | 提供素材の `image/impact-collision-orange.svg` を直接使用する。生成画像の星形へ置き換えない |
| Androidの採用デザイン（2026-10-22） | [公開デモ](https://nevaseme.github.io/safety_confirm/)（ソース：`demo/`）を採用し、第1段階1AでCompose／MapLibreへ移植する。白地・青い操作色、下部の地図／安否、折りたたみ凡例、地図上の無事切替・位置不明人数、下から開く詳細を基準とする |
| 集約の操作（採用デモ） | 広めの縮尺で個別表示へ切り替える（デモはズーム16）。集約タップ時は構成する全スマホが収まる範囲内で拡大する |
| 分断中の独立した地震報告 | 同じ地震の報告として自動でまとめる |
| 同じ地震として集計する範囲 | 最初の報告の操作時刻から30分以内。受信時刻では判定しない |
| 閲覧の継続 | 実災害・訓練とも、管理者が終了するまで継続。期限切れ・延長機能は実装しない |
| 誤操作した本人の報告取消 | 成立前なら可能。取消履歴を保持 |
| 分断中に成立と取消が行き違った場合 | 一度成立した災害は維持し、取消は履歴に残す |
| 災害全体の終了 | 管理者だけが操作する |
| 寝室登録 | 当面は文字入力のみ |
| 巡回ルート | 表示と確認対象・訪問順の手動変更。通行止め情報との連携は後回し |
| 地図の安否表示 | 地図に表示できる位置を持つSOS・応答なしは常に表示。無事・救助済みは表示を切り替えられる |
| 無事と救助済みの記号 | 無事はチェック、救助済みは採用デモの「人＋チェック」。地図・集約・一覧・詳細で統一する |
| 氏名の公開 | SOS・応答なしの人だけ氏名を公開する。無事・救助済みの人の氏名は非公開。人物詳細・各種一覧・記録にも同じ条件を適用する |
| 権限 | 通知を含む必要なすべての権限を許可する前提。不足時は再要求または設定画面での許可へ案内する |
| 初回の安否登録 | その災害に未回答のときだけ、地図の表示前に回答を必須とする。回答済みの再起動では地図を開く |
| 地図と安否の切替 | 画像候補の案1をベースに、下部の「地図／安否」タブを使う。安否の変更は「安否」から行う |
| 建物の配色 | 当面は強い側から薄い黄・明るい橙・濃い橙。不明は灰色＋細い斜線。建物輪郭内に半透明で重ねる。色値は設計書に記載 |
| 位置不明 | 表記は「位置不明 2人」の形式。取得から3日以内の位置は地図に表示し、3日を超えて更新がない人・位置未受信の人は位置不明の一覧で確認する。最後の位置データは保持する |
| 広域表示の動作 | 縮小時に近接するスマホを集約し、拡大時に段階的に分割して最後は個別表示する。吹き出しのタップで、そのグループが分かれる縮尺まで拡大する |
| 広域の吹き出し | 状態別人数をまとめ、1人だけでも吹き出しに統一する。各行は安否のアイコンと人数だけを表示し、状態名の別ラベルや経過時間は省く |
| 衝撃・閉所の表示 | 広域地図には表示せず、拡大時の個別アイコンと人の詳細で確認する |

## 確認状況

今回質問した操作仕様は回答済みで、設計書・実装計画へ反映した。閲覧期限と延長を前提とした旧提案は採用しない。以後、利用者の操作条件を変える追加仕様が必要になった場合は、実装前に確認する。

凡例は通常コンパクトに表示し、タップで展開する。建物の半透明の塗りと集約の挙動は採用デモを基準に、Androidの画面サイズで調整する。第1段階1Aの評価・観測・測位表示には架空データを使う。

## 各段階で選定する事項

| 段階 | 選定・評価するもの |
|---|---|
| 第3段階 | 速報配信元・利用条件、衝撃の保存／関連付け範囲、閉所判定モデル |
| 第4段階 | 対象地域、建物データ、強度評価手法と表示区分 |
| 第6段階 | 名簿更新・役割・失効・削除の運用、位置データの秘匿方式 |
| 第7段階 | 道路データと徒歩経路計算方式 |

測位頻度、SOSメモの文字数などの調整値は設計書の「試作で調整する値」にまとめる。
