# 通報・安否の公開範囲と緊急度表示

状態：利用者との確認結果をまとめた仕様。利用者の「ではWebデモに反映して」を受け、Web案1.6.4へ反映し検証中。Androidと実データの権限制御は未実装。Webでの結果は[実装・確認記録](2026-10-26-report-visibility-web-plan.md)で区別する。

## 確認した目的

道路閉塞・建物倒壊等の通報は地域を越えて共有する一方、通報者の氏名と安否対象者の個人情報は、閲覧者の所属・役割・時間に応じて表示範囲を変える。

「通報者」と「SOS・反応なしの対象者」は別に扱う。番地は通報者の登録住所に基づく表示であり、通報地点やスマホの現在位置と同一とは限らない。

## 利用者が指定・確認した内容

### 通報の表示

| 項目 | 表示する内容・範囲 |
|---|---|
| 緊急度が高 | 提供素材の赤い緊急通報アイコン |
| 緊急度が中・低 | 提供素材の黄色い非緊急通報アイコン |
| 緊急度が未設定 | 既存の旗。非緊急と判定済みとして扱わない |
| 通報の内容 | 地域外の住民にも公開する |
| 一般住民に見せる通報者情報 | 氏名を隠し、登録住所の番地までを表示する。最後の確認への利用者の回答は「番地で」 |
| エリア管理者・自治体職員 | 通報者が誰かを確認できる |

現行の通報入力画面には緊急度の入力欄がなく、通報時に設定することはできない。その後に緊急度を設定・変更できるのは、現行の実装では班長・管理者。今回の確認では緊急度の操作権限の変更指示はない。

### 安否情報の表示

| 閲覧者・条件 | 指定された公開範囲 |
|---|---|
| 同じ町内会の一般住民 | SOS・反応なしの対象者の氏名を表示する。ただし反応なしには下記の3分間の非表示を適用 |
| 他の町内会の住民 | 安否の個人詳細は見せず、統計のみ。道路等の通報内容の公開とは区別する |
| 自治体職員 | SOS等の安否情報は統計のみ。氏名・住所は表示しない。通常の通報者を確認できる権限とは別 |
| スマホ位置が分かる対象者 | SOSでも登録住所の表示は不要 |
| 位置不明の対象者 | 登録住所を利用する。閲覧者に安否の個別閲覧が許されること、反応なしの待機時間が過ぎていることを別に満たす必要がある |

「組」は説明上の例として提示したもので、住所表示や所属判定の必須項目として新設しない。利用者は一般住民への通報者表示として番地を選択した。

### 反応なしの3分間

- 当初の「揺れが収まってから3分」は、その後の利用者の回答で変更された。
- 起点は、緊急地震速報をアプリが受信した時刻と、最初の人が地震報告を行った時刻のうち早い方。
- 片方しかない場合は、その時刻を使う。
- 起点から3分間は、反応なしの対象者の個人情報を表示しない。
- 後続の速報や追加の地震報告では3分を数え直さない。この解釈を利用者が承認した。
- この待機条件は反応なしの個人情報の表示条件であり、SOSの表示を3分間遅らせる指定ではない。
- 3分後も地域・役割による閲覧制限を維持する。時間経過によって他の町内会や自治体職員へ個人情報を公開しない。

## 現在の実装との差分

- Androidには住居の座標・建物・住戸・寝室等の登録がある。住所から町内会・担当エリアを確定し、この公開範囲を適用する登録・権限処理は未実装。
- 現行の参加者設定は一般メンバー・班長・管理者を扱う。自治体職員の安否統計専用の閲覧区分は未追加。
- Androidは速報の受信時刻、地震報告の操作時刻を保存しているが、この3分間の個人情報非表示には未接続。
- 現行のWebデモは架空データであり、今回の地域別・役割別の公開範囲をまだ適用していない。

## 実装時にそろえる表示面

地図記号・集約表示・一覧・人物詳細・建物の登録住民・対応画面・地域集計からの個別表示・CSVを同じ閲覧条件にそろえる。個人情報を隠す画面から別の画面へ移ることで見えてしまう状態を避ける。

公開デモは架空データによる表示確認とし、実データの閲覧制御や本人・役職の確認を実装したと説明しない。画面を更新する際は既存の比較画面を残し、更新版を右側へ追加して公開先でも操作を確認する。

## 実装前に残る整理

- 住所から所属町内会を確定する方法と、その所属を誰が確認するか。
- 自由入力の通報本文に通報者以外の氏名・住所等が書かれた場合の扱い。今回の「通報者の氏名を隠す」は、本文の自動匿名化を承認したものではない。
