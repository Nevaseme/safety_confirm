# CSV確認用サンプル

[pland-review.csv](pland-review.csv)をExcelで開いて確認してください。架空の住民4人と道路の通報1件を、Androidの出力処理で作成しています。

- 無事・救助済みの氏名は空欄です。担当者は活動名で表示します。
- 状況には本人の安否と対応状況を記載します。対応済みと救助済みは別の記録です。
- 「対象ID」は同じ住民・通報を識別する番号です。
- A町内会・B町内会はサンプル用の地域名です。市・区への集計規則は確認中です。

項目の過不足と、日本語が読める状態で開けることを確認してください。アプリの出力ボタンは未追加です。

形式はUTF-8 BOM付きCSVです。[Excelの公式案内](https://support.microsoft.com/en-gb/excel/opening-csv-utf-8-files-correctly-in-excel)に合わせています。
