# PlanD 画面見本

地図・安否・救助記録の操作デモ。

[デモを開く](https://nevaseme.github.io/safety_confirm/)

- 「1.5.4 反映案」の1画面を表示。画面の上に版と追加・変更点を短く記載。
- 一覧案では安否で絞り込んだり、吹き出し下の「一覧」から詳細を開ける。1.5.4反映案では、安否画面でSOSメモ（最大500文字）と「メモだけ保存」を試せる。
- 反映案は一覧案にAndroid 1.5.4の変更を加えたもの。経過時間と吹き出し下の一覧ボタンはAndroidへの移植前。
- 経過時間はデモ内の最初の報告（10月21日14:32）から計算する。
- 表示データは架空。操作結果は再読み込みでリセットされる。
- 無事・救助済みの人は氏名を表示しない。

ローカルではこのフォルダーをHTTPサーバーで開く。地図の読み込みにはインターネット接続が必要。

## 素材・ライブラリ

OpenFreeMap / OpenMapTiles / OpenStreetMap、MapLibre GL JS、Supercluster、Noto Sans JP（OFL）、Phosphor Icons（MIT）。閉所・衝撃のアイコンは提供素材を使用。
