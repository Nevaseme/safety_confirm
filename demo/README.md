# PlanD 画面見本

地図・安否・救助記録の操作デモ。

[デモを開く](https://nevaseme.github.io/safety_confirm/)

- 比較画面は左から「1.5.4 反映案」「Web案 1.6.0」「Web案 1.6.1」「Web案 1.6.2」「Web案 1.6.3」「Web案 1.6.4」「Web案 1.6.5」。1.5.5の比較画面は利用者の指示で削除。各画面の上に版と追加・変更点を短く記載。
- さらに右側に「Web案 1.6.0 対応・地域集計」を追加。[対応デモを直接開く](https://nevaseme.github.io/safety_confirm/?demo=response#response-demo)。Androidの新しい操作画面は未実装。
- [Web案 1.6.1 操作改善](https://nevaseme.github.io/safety_confirm/?demo=feedback#response-feedback-demo)では、通知が解除ボタンを覆わない配置、状態と「担当：北班」等の分離、通報訂正からの取り消し、メニューからの取り消した通報の確認・復元を追加。取り消した通報は通常の一覧・地域集計・CSV・地図から外れ、履歴は残る。SOSは本人の安否画面で更新する。
- 1.6.1の地図では「通報を追加」→地点をタップ→入力・保存で、その地点へ通報を追加できる。「やめる」や別タブへの移動で地点選択を中止する。地域は入力で選び、座標からの自動判定は行わない。
- 新しい「対応」で担当者無し・自分の担当・すべての絞り込み、活動状態、通報追加・訂正、担当調整、対応結果、緊急度、資材要請・不足数、履歴とCSVを試せる。メニューのデモ用役割変更でメンバー・班長・管理者の操作範囲を切り替えられる。
- 「地域集計」で総数とSOS・道路閉塞・建物倒壊・その他を町内会→区→市で表示する。件数を押すと根拠の案件一覧から詳細へ進める。地域未設定も含み、同一案件は上位地域で重複しない。SOSは架空住民1人を1案件として含む。対応完了でも通報記録は残す。
- [Web案 1.6.2](https://nevaseme.github.io/safety_confirm/?demo=stages#response-stages-demo)では「対応状況を変更」から未対応・対応予定・対応中・対応済みを選択する。対応予定は引き受け済み・未着手。担当指定だけでは自動変更しない。「対応を始める」で予定から対応中へ移り、対応済みには結果を入力する。履歴・CSVにも状態が反映される。地域集計は状態を問わず通報を数え、取り消した通報は除外する。1.6.0・1.6.1は従来の3段階を維持する。
- 一覧案では安否で絞り込んだり、吹き出し下の「一覧」から詳細を開ける。1.5.4反映案では、安否画面でSOSメモ（最大500文字）と「メモだけ保存」を試せる。
- 反映案は一覧案にAndroid 1.5.4の変更を加えたもの。経過時間と吹き出し下の一覧ボタンはAndroidへの移植前。
- 経過時間はデモ内の最初の報告（10月21日14:32）から計算する。
- 表示データは架空。操作結果は再読み込みでリセットされる。
- 無事・救助済みの人は氏名を表示しない。

ローカルではこのフォルダーをHTTPサーバーで開く。地図の読み込みにはインターネット接続が必要。

## 素材・ライブラリ

OpenFreeMap / OpenMapTiles / OpenStreetMap、MapLibre GL JS、Supercluster、Noto Sans JP（OFL）、Phosphor Icons（MIT）。閉所・衝撃のアイコンは提供素材を使用。

- [Web案1.6.3](https://nevaseme.github.io/safety_confirm/?demo=assignment#response-assignment-demo)では、他の担当者が付いていて自分が担当していない通報の詳細・各変更画面に「あなたはこの通報の担当ではありません」と表示する。注意は見出し内に残し、操作ボタンを覆わない。注意表示による変更制限は追加せず、従来の役割別の操作範囲を維持する。自分の担当（共同担当を含む）と担当者無しの通報には表示しない。

## Web案1.6.4：公開範囲と通報アイコン

[更新版を直接開く](https://nevaseme.github.io/safety_confirm/?demo=visibility#response-visibility-demo)。右端に追加し、旧版の比較画面はそのまま維持する。

- 上部の「一般住民・東町内会」を押すと、一般住民／エリア管理者／自治体職員、閲覧する町内会、経過時間、速報／最初の地震報告の順序を切り替えられる。開始直後・2分59秒・3分・4分後を試せる。実際の時間経過でも3分の判定を更新する。
- 高は提供された赤いアイコン、中・低は黄色、未設定は旗。通常通報の一覧・地図・詳細・凡例で使う。安否のSOS記号は従来どおり。
- 通報内容は地域外でも表示。一般住民には通報者の番地だけを表示し、エリア管理者には選択町内会の通報者氏名、自治体職員には架空市の通報者氏名も表示する。
- 安否の個別情報は同じ町内会だけ。反応なしは早い方の起点から3分間隠す。地域外と自治体職員には安否統計だけを表示する。地図の非公開対象は町内会単位の統計記号とし、拡大しても個人位置に変わらない。
- 位置が分かるSOS等には登録住所・寝室への導線を出さず、位置不明で閲覧可能な対象だけに表示する。建物の登録住民や地域集計からの個別表示にも同じ条件を使う。
- CSVには現在の立場・地域・時間で閲覧できる通報だけを含める。安否の統計CSVは個人ID・氏名・住所・メモを含めない。
- 役割・地域・時刻は架空データを使った表示確認用。実登録・所属認証、実データのアクセス制御、Androidへの実装は今回行っていない。旧版の比較画面にはこの新しい公開範囲を適用しない。

## Web案1.6.5：町内会の要約と地図整理

[更新版を直接開く](https://nevaseme.github.io/safety_confirm/?demo=map-summary#response-map-demo)。既存の比較画面を残し、その右側に追加。Androidは未反映。

- 広域は町内会の要約、拡大時は閲覧できる個別位置を表示。「町内会」「個別位置」でも切り替えられる。縮小して町内会の記号が密集した場合は、まとめた記号から町内会を選べる。
- 町内会をタップすると、その町内会の安否4区分、未完了の高緊急通報数、資材不足の有無を表示。「詳細を見る」で品名・単位別の不足数と閲覧可能な通報を表示する。対応済み・取り消しは高緊急件数と資材不足から除く。SOSは安否件数と分けて数える。
- 資材は必要数から手配済み数を引いた不足分。架空の西町内会では水8本・毛布3枚、東町内会では水10本・スコップ3本を試せる。
- 通報の三角アイコンから青い四角枠と左右の余白を外し、44pxの操作領域の中央に表示。近接するSOSと通報は同じ記号にまとめ、タップして対象を選べる。個別地点の座標はずらさない。
- 1.6.4の公開範囲と3分間の非公開条件を維持。地域外・自治体職員へ安否の個人情報は表示しない。表示データと操作結果は再読み込みでリセットされる。
