# PlanD Mk1

架空の住民情報で、近くのAndroid端末と安否情報を交換する実験用MVPです。

## 起動

Android Studioでこのフォルダーを開き、Gradleの同期後に `app` を実行します。Android 7.0（API 24）以上と、有効なGoogle Play開発者サービスが必要です。共有試験には実機2台を使います。

## 使い方

1. 「設定」で同じ実験グループ名を入力し、表示名・登録住居・階数・寝る部屋を保存します。住居は緯度経度か地図のタップで指定できます。
2. インターネットが使えるうちに「地図」で登録住居の周囲約2km四方を保存します。「保存済み」となるまで画面を開いておきます。地図未保存でも安否と一覧は使えます。
3. 「安否」で「無事を登録」または「SOSを登録」を押します。
4. 双方でBluetoothとWi-FiをONにし、「共有開始」を押して必要な権限を許可します。Android 12以前では位置情報もONにします。インターネット接続は不要です。
5. 片方で相手を選び「接続する」を押します。双方で表示コードが一致することを確認して接続します。その後は自動で交換・中継します。
6. 接続後は、画面消灯中や別のアプリを使っている間も、接続済みの相手と共有を続けます。背面では新しい相手を探さず、未承認の接続は取り消します。戻ると探索を再開します。
7. 画面または通知の「共有停止」で終了します。背面で接続相手が0台になると自動停止します。再開・再接続はアプリを開いて手動で行ってください。情報と保存済み地図は残ります。地図保存が途中なら、戻って「保存を再開」を押します。

通知には共有状態と接続台数を表示します。通知を押すと安否画面を開きます。通知を許可しなくても共有できます。その場合はアプリから停止してください。端末再起動・強制停止・OSによるプロセス終了後は自動再開しません。OSや端末独自の省電力制御で中断する場合があり、長時間の継続を保証するものではありません。

「Google Play開発者サービスのBluetooth権限が不足」と表示された場合は、画面の「Google Playの権限設定を開く」から「付近のデバイス」を確認してください。PlanD自身の権限だけでは共有を開始できない場合があります。設定を直した後は、PlanDへ戻って手動で共有を開始します。

共有中に受け取った情報は、後で別の端末につなぐと中継されます。グループを変えると表示と共有対象が切り替わります。以前のグループの情報は残ります。

SOSは緊急通報を発信しません。地図の印は登録住居で、現在地や在宅状況ではありません。切断を「応答なし」と判定する機能はありません。

## 地図

- OpenFreeMap Positron / MapLibre Native。
- 保存は1地域、登録住居を中心とする約2km四方、ズーム14〜18。未登録時は東京駅周辺です。地図をスクロールしただけでは保存中心は変わりません。
- 地域を変える場合は保存済み地図を削除し、新しい住居を登録して保存し直します。
- 範囲外や保存ズーム外では通信が必要です。地図データの欠落・更新遅れはあり得ます。
- 出典：OpenFreeMap / OpenMapTiles / OpenStreetMap。地図内の情報ボタンから帰属・ライセンスを表示します。

## 構成

|場所|役割|
|---|---|
|`core`|住民データ・JSON差分同期。Androidに依存しない|
|`data`|Roomによる保存、更新番号の比較|
|`nearby`|Nearbyの発見・接続確認・転送|
|`sharing`|フォアグラウンドサービス、通信処理のキュー、画面との窓口|
|`maps`|オフライン地図管理|
|`ui` / `ui/theme`|Material 3の画面・共通部品・テーマ|
|`PlanViewModel`|画面状態と各処理の連携|

通信形式はバージョン1のJSONです。SUMMARY→REQUEST→RECORD→ACKの順で不足分を交換し、保存してからACKを返します。同一グループ・作成元について更新番号の大きい情報だけを保存し、中継時に作成元と更新番号を変えません。再接続時は保存済みの更新番号を比較します。

グループ名は認証用の秘密鍵ではありません。作成元の電子署名や利用者認証は未実装です。接続する相手を確認し、実在する住民の個人情報では試さないでください。

## ビルドと検証

Android StudioのGradle JDKを利用します。この環境では同梱JBRを使用しました。KotlinはNearbyのバイナリに合わせ2.3.20、KSPは2.3.10です。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

`OfflineMapTest` は初回にインターネットから地図を取得します。Androidのネットワークを有効にして実行してください。`ProfileFlowTest` はテスト用の住民情報を書き込みます。専用エミュレーターで実行してください。

試験手順と確認状況は [TESTING.md](TESTING.md) を参照してください。APKは `app/build/outputs/apk/debug/app-debug.apk` に生成されます。

自動接続・自動再接続、救助完了、センサー、PLATEAU、インターネット同期、iOS・PWA版は今回の対象外です。
